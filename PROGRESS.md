## Sprint 2 — Matcher Agent
Status: **complete** (4 of 4 deliverables; gate met).

Built the CV-to-job matching pipeline end-to-end. `models/profile.py` defines a strict-subset `Profile` (LLM cannot output skills absent from the PDF source text — enforced post-parse) with a deliberately `full_name`-free `to_embedding_text()` so names cannot bias semantic similarity. `tools/cv_parser.py` parses PDFs via `pypdf` and an LLM JSON pass guarded by `JSON_ONLY_PREAMBLE` (added to `BaseAgent` as a Sprint-2 enabling change). `tools/embedder.py` wraps the GWDG `multilingual-e5-large-instruct` endpoint at `EMBED_DIM = 1024`; calibrated the input truncation against a real German CV that breached the 512-token model limit at 300 words — added a two-axis cap (`MAX_INPUT_WORDS = 300`, `MAX_INPUT_CHARS = 1800`) since German compound nouns push the tokens-per-word ratio above 1.8. `agents/matcher_agent.py` orchestrates the two-stage ranking: pgvector cosine via the `match_jobs_for_profile` RPC narrows hundreds of jobs to top-N candidates cheaply, then the LLM gap analysis populates `matched_skills`, `gaps`, and `rationale` only for the survivors — spending LLM tokens where they actually matter. The schema gained four Sprint-2 migrations: `003_resize_embeddings.sql` (1536→1024 dim fix for GWDG), `004_profile_languages.sql`, `005_match_jobs_rpc.sql`, `006_add_matched_skills_to_match_scores.sql`. Shipped `scripts/seed_demo_fixture.py` (records the (prompt, response) pairs from a real GWDG run) and a deterministic regression test `test_matcher_against_sprint2_demo_fixture` that replays them — a peer reviewer can clone the repo and reproduce the slide Top-N without needing GWDG or Supabase access. `scripts/demo_match.py` is the four-phase live closer (Scout → Embed → Match → Print) used in the Sprint 2 presentation. Also fixed pre-existing Sprint 1 lint/type drift (UP017, UP037, generic-`dict` returns in `observability_store.py`) and backfilled three missing Sprint 1 test files. Final state: ruff clean, mypy clean (22 source files), pytest **114 passed**, 0 live calls in tests.
